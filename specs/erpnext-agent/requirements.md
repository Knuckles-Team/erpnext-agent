| `CONN-ERPNEXT-AGENT-R011.1` | **Declare the machine and its single transition function.** `erpnext_agent/lifecycle.py` (new) declares `DocumentState` (Draft, Submitted, Cancelled), `DocumentEvent` (Save, Submit, Cancel, Amend) and a closed table of legal transitions: Draft+Submit to Submitted, Submitted+Cancel to Cancelled, Cancelled+Amend to Draft (a new document that carries `amended_from`), Draft+Save to Draft. Function `transition(state, event, guards)` returns the next state or raises `IllegalTransition`. `IllegalTransition` is a typed error with the fields doctype, name, state, event and a reason code. The reason codes are `NotDraft`, `NotSubmittable`, `NotSubmitted`, `HasSubmittedLinks`, `StaleDocument` and `NotCancelled`. The module is a descriptor the scion-sdk state-machine descriptor row (SCION-GOVERNED-WRITEBACK) consumes. Caller chain: `Api.submit_document`, `Api.cancel_document` and `Api.amend_document` (erpnext_agent/api/api_client_resource.py) call `transition`. Shape: pure functions over enums, no I/O; `state_of(doc)` maps the integer `docstatus` 0, 1, 2 to `DocumentState` once, at the edge. A value outside 0, 1, 2 raises `IllegalTransition`. Sizing: one five-minute row. | `tests/test_document_lifecycle.py::test_every_legal_transition_reaches_its_declared_state`, `tests/test_document_lifecycle.py::test_every_other_state_event_pair_is_refused_with_a_typed_error`, `tests/test_document_lifecycle.py::test_unknown_docstatus_value_is_refused` |
